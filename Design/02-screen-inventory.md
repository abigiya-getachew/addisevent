## Screen Dependencies (Critical Path)

```
A-01 Home → A-03 Event Detail → A-04 Checkout Review → A-05 Payment → A-06 Processing → A-07 Confirmation → A-09 Ticket QR
   │                                                                    ↑
   └→ A-02 Search ─→ A-03 (same path)                                   │
                                                                        │
O-04 Scanner ← (validates tickets generated by A-07) ───────────────────┘

D-01 Moderation → D-02 Event Creator → (publishes to) A-01 Home
```

**Note**: A-01, A-02, A-03 are accessible without login. A-04 supports guest checkout. Account creation prompted post-booking only.
